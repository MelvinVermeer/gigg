# Settings

One page per band: `/<band>/settings`, reached from the user menu (avatar with the first letter of the email or display name; also: bands (switch), manual, feedback, log out).

- **You:** display name (shown instead of the email everywhere), email, passkeys (add, list, delete via a bin icon), theme (Light / Dark / System segmented control; per device, in a cookie), language (select with flags), calendar feed link (see [events.md](events.md)).
- **The band** (members): venues and contacts. Rarely change, so they're edited here, not in the main navigation. Archived ones leave the event form's search boxes but stay on old events.
- **Members** (members only): list, invite by email as member or reader (existing people get their role changed), remove (bin icon). Removing archives the membership; you can't remove yourself.
