# Availability

A member asks the band whether they can make an event ("check availability").

- Asks members and readers; each gets an email with a link to a page (`/availability/<token>`, in the recipient's language) where they answer without logging in. The token is random; only its hash is stored.
- Answers: yes / maybe / no (coloured). A note can be added on *maybe* only.
- Shown on the event, sorted yes > maybe > no > waiting. Once answered, the form is hidden, with an Edit button by your name.
- Closes automatically when everyone has answered; shown as a segmented count badge. A closed check can be reopened.
- Asking, answering and closing show up in [history](history.md).
