# Admin and feedback

## Admin

`/admin`, for the instance admin: create bands (with a first member), delete them (soft delete, then permanent). Stats: bands, users, DB size, file size per band. Feedback overview.

## Feedback

Anyone in a band sends feedback from the account menu (`/<band>/feedback`); the admin page lists it and items can be marked done (hidden unless “Show all”).

## Manual

A short static in-app manual at `/manual`, linked from the account menu.
