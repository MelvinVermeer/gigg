# History

Each edit page links to that item's history (`/<band>/history?item=<id>`): every save that touched it, in plain language ("Archived song “Closer”", "Changed setlist “Wedding”"), who and when, newest first. A save folds open to show each field before → after (setlists and blocks as their song lists). Also covers member changes and availability asking/answering/closing. No undo.

Underneath: every write goes through one place and is logged by an audit trigger. Archiving moves from the edit form; archived items disappear from lists and links but stay on old records.
