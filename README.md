# Gigg

Gigs, setlists and riders for bands. Installable PWA. See [idea.md](idea.md) and [data-model.md](data-model.md).

## Develop

```sh
pnpm install
pnpm dev          # http://localhost:3000, no accounts or database needed
```

Without `DATABASE_URL` the app runs in **local mode**: Postgres in WASM (PGlite) in `.pglite/`, migrated and seeded on start. Sign in as `member@example.com`, `reader@example.com` or `admin@example.com` (admin: `/admin` in the user menu); the sign-in link is printed in the console. Delete `.pglite/` to start fresh. A production build (`pnpm build && pnpm start`) refuses local mode unless `LOCAL_MODE=1` is set.

## Test

```sh
pnpm typecheck
pnpm test         # Vitest: server logic against in-memory Postgres
pnpm test:e2e     # Playwright: production build in local mode
```

CI runs all three on every PR and every push to `main`.

## Text and languages

All UI text lives in `src/lib/i18n.en.ts` (the source) and `src/lib/i18n.nl.ts`; the type check fails when Dutch misses a key, and `src/lib/i18n.test.ts` fails on English typed straight into a page or component. Components get the dictionary with `useT()`. The manual (`src/routes/manual.tsx`) is prose per language. Errors the UI shows are thrown by key (`errors` in the dictionary).

## Database

- Schema: `src/server/db/schema.ts` (app) and `auth-schema.ts` (generated by Better Auth).
- After a schema change: `pnpm db:generate`, commit the migration in `drizzle/`.
- New table? Add it to the trigger list in a migration (see `drizzle/0002_audit.sql`); a test fails otherwise.
- Production: `DATABASE_URL=... pnpm db:migrate`. gigg.band does this in CI on every push to `main` (the `migrate` job; repo secret `DATABASE_URL_UNPOOLED`). Vercel deploys in parallel, so keep migrations additive.

## Self-host on Vercel

1. Fork, import in Vercel.
2. Add a Postgres database (e.g. Neon from the Vercel marketplace); it sets `DATABASE_URL`.
3. Add a Blob store (Storage tab; it sets `BLOB_READ_WRITE_TOKEN`) for file uploads, up to 100 MB each.
4. Set the other variables from `.env.example` (email: a free resend.com account with your domain verified, then `RESEND_API_KEY`).
5. Run `pnpm db:migrate` against the database, then deploy.
6. Sign in with an email from `ADMIN_EMAILS`.
